# iOS 開発セットアップ手順（絶景道アプリ）

作成日: 2026-09-03

本リポジトリの `ios/` 配下は SwiftUI アプリの土台コードである。Linux 環境で作成したため、Mac 上でのビルド確認は未実施。以下の手順で Xcode プロジェクトを生成し、動作確認を行う。

## 1. 必要なもの

- Mac（macOS 14 以降）と Xcode 16 以降
- Apple Developer Program（TestFlight 配布・実機の位置情報バックグラウンド確認に必要）
- Supabase プロジェクト（無料枠で可）
- Google Cloud の OAuth クライアント ID（iOS 用）

## 2. プロジェクト生成

```bash
brew install xcodegen
cd ios
xcodegen generate
open ZekkeiTouring.xcodeproj
```

XcodeGen は `ios/project.yml` から Xcode プロジェクトを生成する。依存パッケージ（supabase-swift、GoogleSignIn-iOS）は Swift Package Manager で自動取得される。

## 3. 接続先の設定

`ios/project.yml` の以下 3 項目を差し替える。値は各ダッシュボードから取得する。

| 項目 | 取得元 |
|---|---|
| `SUPABASE_URL` | Supabase > Project Settings > API > Project URL |
| `SUPABASE_ANON_KEY` | 同上 > anon public key |
| `GOOGLE_CLIENT_ID` | Google Cloud Console > 認証情報 > iOS 用 OAuth クライアント |

同じく `CFBundleURLSchemes` の `com.googleusercontent.apps.REPLACE...` を、Google の「iOS URL スキーム（REVERSED_CLIENT_ID）」に差し替える。

差し替え後に `xcodegen generate` を再実行する。値が未設定の間は、アプリはテスト用データ（モック）で動作する。

## 3.5 Supabase アカウント・プロジェクト作成時の注意

- **リージョン**: 「Northeast Asia (Tokyo)」を選ぶ。日本の利用者の応答が速く、後から変更できない
- **プロジェクト名**: `zekkei-touring`。データベースのパスワードは自動生成のまま、パスワード管理ツールに保存する（後で再表示できない）
- **プラン**: 開発中は Free。Free は 1 週間操作が無いと一時停止するので、公開前に Pro（月 $25）へ上げる。組織（Organization）は個人名で良い
- **拡張機能**: PostGIS は SQL の先頭（`create extension postgis`）で有効化されるため、画面操作は不要
- **控える値（3 つ）**: Project Settings → API の「Project URL」「anon public key」「service_role key」。service_role は管理用で、アプリには入れない（サーバー側と自動収集の流し込みだけで使う）
- **認証（Authentication → Providers）**: Google を有効化し、Google Cloud の「iOS 用 OAuth クライアント ID」を登録する。Apple を有効化するには Apple Developer Program の登録が必要なので、TestFlight 直前で良い
- **Storage**: バケットは SQL で作られるので手動作成は不要
- **Security**: 「Enable email confirmations」は既定のままで良い（Google/Apple ログインのみ使うため影響しない）
- **自動収集の流し込み**: `tools/seedpipeline/out/<日付>_seed_roads_auto.sql` は数 MB あるため、SQL Editor の貼り付けではなく Supabase CLI（`psql` 相当）で流す。手順は流し込み時に別途案内する
- **費用アラート**: Organization → Billing → Spend cap を「有効」にしておくと、想定外の課金が止まる

## 4. データベースの初期化（Mac から、追加インストール不要）

接続情報を対話で登録してから、`tools/supabase/20260905_db_admin.py` で SQL を適用する。Personal Access Token は https://supabase.com/dashboard/account/tokens で作成する（名前は `zekkei-admin` 等）。

```bash
cd tools/supabase
./20260905_setup_supabase.sh          # URL・Publishable key・Secret key・Personal Access Token を登録し検証
source ~/.zekkei_supabase
python3 20260905_db_admin.py migrate  # supabase/migrations/*.sql を日付順に適用（適用済みは飛ばす）
python3 20260905_db_admin.py seed     # 手作業シード 22 本と、自動収集シード（最新）を流し込む。何度流しても二重登録されない
python3 20260905_db_admin.py stats    # 件数の確認
```

Supabase の Authentication > Providers で Google と Apple を有効にし、Google のクライアント ID を登録する。

月次無料枠の付与は `grant_monthly_free_credits()` を毎月 1 日に実行する。Supabase の pg_cron 拡張で以下を登録する。

```sql
select cron.schedule('grant-monthly-credits', '5 0 1 * *', $$select public.grant_monthly_free_credits()$$);
```

## 5. 動作確認の順序

1. シミュレータで起動し、「探す」タブにサンプルの絶景道が表示されることを確認する。
2. 実機で「記録」タブから記録を開始し、位置情報の「常に許可」ダイアログを確認する。
3. 走行後に記録を終了し、区間の切り出し画面でスライダーが動くことを確認する。
4. ログイン後に投稿し、Supabase の `zekkei_roads` と `road_ratings` に行が入ること、閲覧枠が 3 件増えることを確認する。

## 5.5 デザイン

画面デザインは `docs/design/20260905_v2_dark/`（Claude Design の成果物: 8 画面のスクリーンショット、仕様 README、動くモック HTML）を正とする。配色・文字・部品の共通定義は `ios/ZekkeiTouring/Design/Theme.swift` にあり、各画面はこれを使って組んである。

## 6. 構成

```
ios/
  project.yml                      XcodeGen 定義（権限説明文・バックグラウンド設定を含む）
  ZekkeiTouring/
    App/        ZekkeiTouringApp.swift, AppState.swift
    Design/     Theme.swift          配色・文字・共通部品（ガラスカード、主ボタン、タグ、タイル、5 軸バー、星）
    Models/     Models.swift        走行記録・絶景道・評価・閲覧枠の型
    Services/   RideRecorder.swift  GPS 記録（バックグラウンド対応・自動一時停止）
                RideStore.swift     走行記録の端末内保存
                GeoUtils.swift      距離・曲がり具合・間引き・プライバシーゾーン除外
                Backend.swift       サーバー窓口の定義とモック
                SupabaseBackend.swift  Supabase 実装
                MediaProcessor.swift 写真の縮小・動画の圧縮（720p・30秒）
    Views/      MediaPickerSection  写真・動画の選択と添付
                ExploreMapView      周辺の絶景道を地図表示
                RoadDetailView      詳細（閲覧枠で解放）・通報・ナビ連携
                RecordView          記録の開始・終了、走行記録一覧
                TrimView            区間の切り出し
                RateView            多軸評価と投稿（既存道との重なり判定を含む）
                SignInView          Google / Apple ログイン
                ProfileView         プラン・閲覧枠・プライバシーゾーン・連絡先
supabase/migrations/20260903_init.sql  DB 設計・権限・閲覧枠の台帳・重なり判定関数
```
