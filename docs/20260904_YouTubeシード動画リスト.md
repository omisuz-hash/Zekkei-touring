## 2. 分析結果

- **地域の偏り**: 17 本中 13 本が長野・山梨・東京西部・埼玉・静岡東部の「関東甲信」に集中。初期対象地域を関東甲信に絞る判断と整合する。
- **チャンネルの2類型**: (a) モトブログ型（RY、STOMP、しーまん、アヤセ、まりさん、さてバイ）は 1 本 1 ルートで道の特定がしやすい。(b) 絶景紹介型（sharin-jin）は「穴場」の密度が高く、本企画が狙う「知られていない道」の供給源として有望。
- **「知られていない道」の実例**: 若狭幹線林道、飛騨の山頂道路、信州 Best20 の下位項目。こうした道は既存アプリ・ガイドブックに載っておらず、差別化の核になる。
- **概要欄の取得**: サーバー環境からは YouTube の概要欄が取得できなかった。YouTube Data API（無料枠あり）を使えばタイトル・概要欄・再生数を自動取得できるため、シード投入ツールはこれを前提に設計する。

## 3. 推奨案（シード投入の進め方）

1. **確度 A/B の 12 本を先行投入**し、位置の精度は「概略」と明示。実走投稿が重なると既存道として評価が集積する設計のため、精度は運用で上がる。
2. **確度 C の 5 本は視聴して区間を特定**する。特に #14（Best20）と #17（飛騨）は複数の穴場を含む可能性が高い。
3. **チャンネルへの還元**: 各絶景道の詳細に動画リンクとチャンネル名を表示する。公開前に主要チャンネル（しーまん、sharin-jin、STOMP）へ掲載の連絡を行うと、初期ユーザー獲得の協力も見込める。
4. **YouTube Data API の利用**: シード投入ツール（次フェーズ）で概要欄からルート情報を自動抽出する。API の無料枠（1 日 10,000 ユニット）で十分。

## 4. 動画の扱いに関する規約上の整理

- 動画はアプリ内に埋め込まず、リンクとサムネイルで紹介する。YouTube の API 規約は、埋め込みプレーヤーの視聴に課金や条件を付けることを禁じているため、動画リンクは閲覧枠の外（無料側）に置く。
- サムネイルは YouTube の公式サムネイル URL を参照する。動画ファイルの複製・保存は行わない。
