# 動画投稿者への連絡文面（謝意版）

絶景道のデータは、ツーリング動画の投稿者が公開した内容を元にしている。その謝意を伝え、
招待コードを渡すための文面。**紹介は求めない。**

TestFlight 配布の段階では導入の手間が大きく、紹介をお願いしても受け手が離脱する。
関係を作ることだけを目的とし、紹介の相談は正式公開の後に改めて行う。

## 1. 送り先の見つけ方

| 方法 | 備考 |
|---|---|
| **概要欄に書かれたメール** | 最も確実。そのまま送れる |
| **チャンネルの「概要」→ ビジネス用のメールアドレス** | 概要欄に書いていなくても登録している人が多い。パソコンから開き、認証を通すと表示される |
| 概要欄の X / Instagram へ DM | メールが無い場合の次善 |
| 動画のコメント欄 | 最後の手段。公開の場なので宣伝に見られやすい |

送り先の一覧は `tools/seedpipeline/out/*_contributors*.csv`。チャンネル URL が入っているため、
そこから「概要」を開くのが早い。

**送信は 1 日数通ずつに留める。**同じ文面を一度に大量送信すると迷惑メール扱いになる。

## 2. 差し込む項目

| 箇所 | 入れるもの |
|---|---|
| `○○` | チャンネル名 |
| `XXXXXXXX` | **その相手専用の招待コード**（`tools/supabase/out/*_promo_codes.csv` が対応表） |

差し込みは手作業でなくてよい。次の 1 行で、送付先の一覧と文面が揃った形で出る。

```bash
cd tools/supabase && source ~/.zekkei_supabase
python3 20260905_db_admin.py outreach --contributors ../seedpipeline/out/20261109_contributors_stats.csv
```

`out/<日付>_outreach.csv`（送付先・コード・送付日を 1 つにまとめた表）と、
`out/mails/` に 1 通ずつの文面が出る。送ったら `--sent` で台帳に記録する。

コードは配布先ごとに分けてある。使用回数がそのままチャンネル別の送客数になるため、
使い回さないこと。使用状況は `python3 20260905_db_admin.py codes` で確認できる。

**招待コードの期限は 2 つある。**混同しないこと。

- コードを**使い始められる**期限: 2027 年 6 月 30 日
- 無料で使える期間: **使った日から 365 日**

## 5. 文面の設計意図

書き換える際も、次の 3 点は残すこと。

- **「多くの方の動画を組み合わせて」を早い段階に置く。**その人の動画だけを使ったという誤解を避け、
  特定個人のコンテンツを無断で利用したのではないかという警戒を先回りして解くため
- **「掲載を望まれない場合は取り下げます」を必ず入れる。**こちらから先に申し出ることで相手に
  主導権を渡せる。これが無いと、親切な連絡が一方的な通告に見える
- **紹介を求めていないことを明記する。**求めていないのに紹介してもらえたときが最も良い形であり、
  期待を示すと断りにくさが相手の負担になる

お問い合わせ先を署名と分けて節に立てているのは、署名の中のアドレスが「差出人の表示」として
読み流されるため。意見を求める呼びかけと並べて初めて、送ってよいものだと伝わる。

## 6. 知人向けとの違い

知人へは共通コード（180 日間・30 人まで）を使い、文面も短い案内で足りる。
こちらの文面は動画投稿者向けであり、**データの出どころを説明する責任がある点**が異なる。
