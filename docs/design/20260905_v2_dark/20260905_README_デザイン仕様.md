# Handoff: 絶景道（Zekkei-do）v2 ダーク UI

## Overview
バイクツーリング向け「道の口コミ地図」アプリ iOS 版の全 8 画面。ユーザーは地図上で絶景道を探し、閲覧枠を使って詳細を見、走行を記録し、公開区間を切り出して 5 軸で評価投稿する。方向性は「ハードでクール、正確で堅実」。黒〜ディープブルー地、衛星調ダーク地図、Tidal blue アクセント。

対象リポジトリ: `omisuz-hash/Zekkei-touring`（現時点は README のみ。SwiftUI + MapKit を想定）。
元仕様: `uploads/20260905_UIDesignHAndoff_Zekkei-doh.md`（本フォルダにも同梱）。

## About the Design Files
同梱の `Zekkei-doh v2 dark.dc.html` は **HTML で作成したデザイン参照（動くモック）** であり、そのまま出荷するコードではない。SwiftUI（既存環境がなければ SwiftUI + MapKit を選択）で **同じ見た目・挙動を再現** すること。地図は SVG による疑似描画なので、実装では MapKit の `.standard` ダーク（`.mapStyle(.standard(elevation:.realistic))` または `.imagery`）＋ `MapPolyline` オーバーレイに置き換える。

`Zekkei-doh.dc.html` は旧 v1（ライト・橙）。参照不要、履歴として同梱。

## Fidelity
**High-fidelity。** 色・字サイズ・余白・角丸は本 README と HTML の値どおりに再現する。ただし地図テクスチャ・写真サムネはプレースホルダ。

## Screens / Views

### 1. Explore Map（探す）`ExploreMapView`
- 目的: 地図上の絶景道を探し、線をタップして詳細シートを開く。
- 地図: MapKit ダーク。**絶景道は実道路の線形に完全に重ねて描く**（独立した浮いた線にしない）。線は 3 段階
  - 絶景度 4.5+: `#8ED4F5` 5pt + 外側グロー（同色 16pt, opacity .38, blur 5）+ 中央ハイライト白 1.2pt opacity .7
  - 3.5+: `#1B9BD6` 4pt + グロー（12pt, .35）
  - 評価が少ない: `#7C8B95` 3.5pt、グローなし
- 始点マーカー: 空港コード風タグ。`#0F2A38` 地、1.2pt `#5FB4DD` 枠、角丸 6、白 10pt Bold 英字コード（例 VENUS / R142）。左に ▶（動画由来）または ★（投稿由来）。評価少は地 `#1A2126` 枠 `#7C8B95`。
- 現在地: 白 7pt 円（黒 2pt 縁）+ 白 8%/10% の同心円ハロー r22/r40。
- 上部（top 62）: 検索バー h44 角丸 14、`rgba(20,24,28,.82)` + blur 20、枠 `rgba(255,255,255,.07)`、プレースホルダ「地名・道名で探す」15pt `#8F9BA3`。右に閲覧枠バッジ（同スタイル、縦積み: 「閲覧枠」8pt letter-spacing .14em `#8F9BA3` / 数値 17pt Bold 白 tabular）。
- 左下（bottom 120）: 凡例カード。見出し「絶景度」8pt、行 11pt `#C5CED3`、色見本 18×3。
- 右下: コンパス・現在地ボタン 44×44、角丸 14、同ガラス。

## Interactions & Behavior
- 地図の線タップ → 詳細シートを部分展開（概要のみ）。「閲覧枠を使う」→ 枠 −1、シート内容が 5 軸〜ナビまで展開。枠 0 なら月額プラン導線を強調。
- 記録: 開始で 1 秒ごとに時間更新、距離は GPS から算出。終了 → 自動で Trim へ。
- Trim: スライダーは start/end の大小が逆転しても min/max で正規化。区間 < 500 m は送信不可。
- Rate: 道名必須。送信時に既存道との重なり判定（例では 85%）→ ダイアログ → 完了で枠 +3。
- スライダーつまみ 28pt、タブ・ボタンのタップ領域は 44pt 以上。
- アニメーション: 状態ドット pulse 1.4s（opacity 1→.35）。その他は iOS 標準トランジション。

## State Management
- `tickets: Int`（閲覧枠、既定 3）、`unlockedRoadIDs: Set`
- `recording: idle | recording | paused`, `elapsed: TimeInterval`, `distance: Double`, `track: [CLLocation]`
- `trimStart / trimEnd: Double`（km）
- `rating: {view, ride, wind, rest, park: 1...5}`, `seasons: Set<String>`, `roadName`, `media: [Asset]`
- `privacyZone: {center: CLLocationCoordinate2D, radius: 300...3000}`
- 取得: 道一覧（表示範囲）、道詳細（解放後のみ）、走行記録（端末内保存）。
